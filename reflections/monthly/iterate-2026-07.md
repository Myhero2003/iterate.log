- 6月に立てた目標の達成度は、**業務に慣れる：3 / 自作ゲームの開発再開：1 / noteの執筆再開：4**。

## 🚀 成果・成長したこと
- **note:** 数ヶ月持ち越していた「執筆再開」を回収。7/5に「“それっぽい”配信画面の作り方｜OBS×スプレッドシート実践編」を投稿した。6月の目標に書いた「OBS関連を書いてみたい」を、テーマまでそのまま実行できた形
- **個人開発:** 「なんでも入れられる自分用の辞書」を作りたくて、Next.js + TypeScript + Tailwind CSS で用語集Wikiを試作。`[[用語名]]` 記法による内部リンクとスマホ向けのサイドバー対応まで実装（※開発は現在停止中）
- **生活:** 部屋作りを通して、神戸での暮らしがだいぶ落ち着いた

## 🛠 課題と来月の対策
- **業務のキャッチアップ:** 専門用語や略称が多く、会議で飛び交う内容についていくのが難しい。まだ「聞かないと動けない」状態なので、出てきた用語をその場でメモして自分用に蓄積していく
- **過去資料の探索:** 長期的なプロジェクトが多く、蓄積された過去資料の中から参照すべきものを探すのに苦労した。ドメイン知識の不足が原因なので、資料の全体像と在り処から押さえる
- **自作ゲーム（Unity）:** 6月・7月と2ヶ月連続で未着手。8月は目標を「個人開発を1つ」に絞り、対象を決めてから着手する
- **基本情報技術者:** 再開にも時間がかかるため、保留の判断を継続する。ただし「いずれ絶対に取る」という意思は変わっていない
- **noteのネタ不足:** 書けない主因は時間や気力ではなくネタ切れ。個人開発や業務で学んだことをそのまま記事のネタに回す

## ☕️ ライフスタイル・リフレッシュ

- **esports/ゲーム:** 引き続き大会配信を視聴。9月の**東京ゲームショー**参加が決まったので、その周辺の情報も追い始めた
