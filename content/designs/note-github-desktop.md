## 作ったもの

記事「[【GitHub Desktop】たったこれだけでGitの難易度がバグレベルに下がる！？](https://note.com/mahiro05_02/n/n269ea23e6eac)」のバナー。

## 構成

実際の操作画面のスクリーンショットを斜めに配置し、手前にピンクのグラデーション + 縁取りの大見出しを重ねた。「New Repository...」のメニューを拡大して、記事の要点が一目で分かるようにしている。右上には手書き風の縦書きで「とりあえずコレやれ！」を配置。

1本目のミニマルな路線から、**配信サムネイル寄りの見せ方に切り替えた回**。
