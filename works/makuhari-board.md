## 概要

9月に参加するゲームイベントに向けて、**会場で実際に使うこと**を前提に作った個人用の周遊アプリです。

タイムライン・フロアマップ・開催概要・持ち物リスト・グッズ購入リストの5画面を、`index.html` **1ファイル**に収めています。ビルド不要、依存パッケージなし、フレームワークなし。

**公開中** → [myhero2003.github.io/makuhari-board-26](https://myhero2003.github.io/makuhari-board-26/)

**リポジトリ** → [github.com/Myhero2003/makuhari-board-26](https://github.com/Myhero2003/makuhari-board-26)

> これは非公式の個人ツールです。イベントの主催者・会場運営・出展社とは一切関係がありません。
> 公式ロゴ・ブランドアセット・公式会場図は使用しておらず、配色・アイコン・フロアマップはすべて自作です。

## 技術構成

| 技術 | 用途 |
|------|------|
| **HTML / CSS / JavaScript** | すべて `index.html` の1ファイルに同梱（約2,000行） |
| **localStorage** | 予定・リストの保存先。端末内のみ |
| **インラインSVG** | アイコン・フロアマップの模式図 |
| **GitHub Pages** | 配信 |

外部API・CDN・Webフォントを一切読み込まず、フォントはシステムフォントのみを使っています。

## 主な機能

- **タイムライン**: 日程ごとに 8:00〜21:00 の縦軸へ予定をブロックで配置。「シフト」と「周遊プラン」の2種類を**同じ時間軸に並べられる**ので、来場者としての予定だけでなく、スタッフとして入る場合のシフト管理にも使える
- **重複の警告**: 予定が重なると赤枠で警告し、予定と予定のあいだの**空き時間を自動計算**して表示
- **フロアマップ**: 自作の模式図の上に、予定のあるホールへピンを立てる。同じホールに複数あれば件数を表示し、ピンチ拡大・ドラッグ移動に対応
- **持ち物 / グッズ購入リスト**: グッズ側は合計予算と購入済み・未購入の内訳を集計
- **バックアップ**: 全データをJSONテキストとして書き出し・復元

## 工夫した点

### 「会場で使う」から逆算した制約

会場は電波が不安定で、屋内は暗く、片手で見る場面が多い ——という前提を先に置き、そこから技術選択を決めました。

- **通信しない**: 起動後に外部へ問い合わせに行く要素をすべて排除した。CDNもWebフォントも使わないのはこのため
- **単一ファイル**: 依存を持たないので、壊れる箇所が原理的に少ない
- **高コントラストのダークUI**: 暗い会場でのチラ見に合わせた配色
- **ホーム画面に追加して全画面起動**: ノッチとホームバーを避けるレイアウトにした

### できないことを、できないと書く

起動後は通信しませんが、**ホーム画面から開く瞬間のページ読み込みには通信が必要**です。Service Worker を入れていないため完全なオフライン起動は保証できません。

ここを「オフライン対応」と言い切ってしまうと、会場で開けなかったときに困るのは自分自身です。READMEには**現状できないことと、その回避策（電波のある場所で一度開いておく）**を明記しました。

### 実装の前に画面を固める

`design/` に、iPhone実寸（390×844）のアートボードで5画面ぶんのデザインと、配色・余白のトークンを先に作ってから実装に入りました。画面ごとに色を決め直さずに済んでいます。
