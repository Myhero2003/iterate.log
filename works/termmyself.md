## 概要

「学んだ用語を、何でも放り込んでおける自分専用の辞書がほしい」という動機から作った、Wiki風の用語集Webアプリです。

用語は `content/terms/` 以下に **1用語1ファイル** のMarkdownとして置くだけで、サイドバーの一覧・検索・詳細表示まで自動的に構成されます。現在はBlenderの用語を題材に試作しています。

## 技術構成

| 技術 | 用途 |
|------|------|
| **Next.js (App Router)** | ルーティング・Server Componentでのビルド時読み込み |
| **TypeScript** | 型定義（用語データの構造化） |
| **Tailwind CSS** | スタイリング・レスポンシブ対応 |
| **gray-matter / marked** | Front Matterの解析とMarkdownのHTML変換 |

## 主な機能

- **`[[用語名]]` 記法による内部リンク**: 本文中の記法を、タイトル・ファイル名のどちらからでも解決して内部リンクに変換。存在しない用語へのリンクは赤い点線で表示され、「まだ書いていない用語」がひと目で分かる
- **リアルタイム検索**: 用語名・説明・タグを対象に、入力しながら絞り込み
- **カテゴリ別サイドバー**: Front Matterの `category` で自動グループ化
- **モバイル対応**: 画面幅に応じてサイドバーをドロワー化

## 工夫した点

Server Component 側でビルド時に全用語を読み込み、リンク解決まで済ませた上でクライアントに渡す構成にしました。検索や表示切り替えといったインタラクションだけをクライアント側に持たせることで、用語が増えても表示は軽いままにしています。

## 今後の展望

- 未定義リンク（まだ書いていない用語）の一覧化
- 用語を参照している他の用語を表示するバックリンク機能
- 本文を含めた全文検索
